# Hi, I'm Kemal Eren Sivrikaya

## Unity Developer | Gameplay, UI & Production Tools

I develop commercial Unity experiences with a focus on gameplay systems, reusable UI architecture, designer-facing tools, and data-driven production workflows. I enjoy turning complex design requirements into maintainable systems that help both players and development teams.

## Professional Focus

- **Gameplay Programming:** Building interactive systems with configurable rules, progression, input handling, animation, and responsive feedback.
- **Unity Production Tools:** Creating custom editors and visual workflows that allow designers to manage content without manual code changes.
- **UI Architecture:** Developing reusable interfaces for mouse, keyboard, and gamepad with validation, navigation, and multiple presentation states.
- **Data-Driven Workflows:** Connecting ScriptableObjects, spreadsheets, JSON data, custom inspectors, and live previews to support faster content iteration.
- **Systems Integration:** Bringing localization, audio, transitions, shaders, animation, economy, and persistent progression together across a complete player experience.

## Commercial Project Experience

Contributed across a nine-month commercial Unity production, authoring **389 commits (309 non-merge)** and taking ownership of gameplay features, UI systems, production tools, and technical integrations.
