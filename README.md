# Hi, I'm Eren

I'm a Unity developer interested in gameplay programming, game tools, UI systems, and game design.

Most of my work is in C#. I like building systems that are easy to change as a project grows, especially when designers or other team members need to work with them. This often means writing custom Unity editor tools, keeping game data separate from logic, and spending a fair amount of time on small workflow problems that would otherwise slow the team down.

## What I've been working on

My main recent project is [Gemmy Gems: A Cozy Shop Sim](https://store.steampowered.com/app/4103850/Gemmy_Gems_A_Cozy_Shop_Sim/), a commercial Unity game that I worked on for around nine months.

I made 389 commits to the project, 309 of them excluding merges. My work covered gameplay features, UI, editor tools, localization, audio integration, progression systems, and general production support.

A large part of the job was building tools for the rest of the team. I made custom editor windows and inspectors so content could be created and checked inside Unity without editing code. I also worked on spreadsheet and JSON import/export, validation, previews, scene syncing, and debugging tools.

On the player-facing side, I built gameplay systems from prototype through implementation, as well as reusable UI that works with mouse, keyboard, and gamepad. I also handled parts of the economy and progression, tutorials, English and Turkish localization, FMOD integration, transitions, shaders, animation, and plenty of bug fixing along the way.
